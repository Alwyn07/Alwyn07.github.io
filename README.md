## Design direction

The site uses a restrained editorial system rather than a template-heavy portfolio: strong typography, a limited monochrome palette, visible grid structure, restrained motion, and project-first content.

The content is intentionally factual. Project descriptions, technologies, education, and credentials are presented without invented metrics, testimonials, client claims, or fabricated experience.
